## 环境说明

- C++ 编译环境：MinGW / g++
- Python 版本：Python 3.x
- 编辑器：VS Code

### C++ 编译运行方式

```bash
g++ 文件名.cpp -o 文件名
./文件名
```

### Python 运行方式

```bash
python 文件名.py
```

## 每日上传命令

```bash
git add .
git commit -m "日期: 练习内容"
git push origin main
```

## 提交记录格式

- `init:` 初始化仓库
- `cpp:` C++ 相关练习
- `python:` Python 相关练习
- `fix:` 修复问题
- `docs:` 文档更新

示例：

```bash
git commit -m "cpp: 2026-10-16 运算符重载练习"
```
